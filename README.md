# 像素机甲对战 · Pixel Mecha Battle

一个基于 HTML5 Canvas 的双人本地像素风格机甲格斗游戏。单文件实现，无需任何依赖，打开即玩。

## 游戏截图

画面采用 16×22 像素精灵 + 320×192 逻辑分辨率，经 CSS 放大呈现复古 CRT 质感。

## 功能特性

* **双人本地对战**：P1（蓝色机甲）与 P2（红色机甲）同屏格斗

* **完整格斗系统**：移动、跳跃、攻击、防御、受击、死亡结算

* **丰富的动画帧**：

  * 待机：4 帧呼吸循环 + 天线指示灯闪烁 + 面罩高光移动

  * 行走：4 帧腿部交替 + 身体起伏 + 上身前倾

  * 攻击：蓄力 → 出拳（带挥砍光弧）→ 收招 三段式

  * 跳跃：双腿收起、双臂微张的腾空姿态

  * 受击：面罩变叉眼 + 核心受损收窄

* **战斗机制**：

  * 每方 100 HP，攻击造成 14 点伤害

  * 防御可将伤害削减至 25%，并附带击退与硬直

  * 攻击命中判定盒、受击无敌帧

* **视觉反馈**：

  * 屏幕震动（落地 / 受击）

  * 伤害飘字（普通伤害红色、防御减伤灰色）

  * 落地扬尘粒子

  * 防御能量护盾脉冲 + 边缘高光 + 流动能量粒子

  * 攻击挥砍弧形光痕

  * CRT 扫描线叠加效果

* **音效与背景音乐**：

  * 全部通过 Web Audio API 程序化合成（无外部音频文件），SFX 与 BGM 分总线管理

  * 音效：跳跃、攻击蓄力、挥砍轨迹、命中、格挡、举盾、受击、落地、胜利、重开

  * BGM：16 步循环战斗主题（旋律 + 贝斯 + 底鼓 + 军鼓 + 踩镲），前瞻调度器自动循环

  * 首次按键自动解锁音频并启动 BGM，`M` 键静音切换（画面右上角显示 MUTE 标识）

## 操作方式

| 玩家        | 移动        | 跳跃  | 攻击  | 防御  |
| --------- | --------- | --- | --- | --- |
| **P1（蓝）** | `A` / `D` | `W` | `F` | `G` |
| **P2（红）** | `←` / `→` | `↑` | `J` | `K` |

* `R`：重新开始对局
* `M`：静音 / 取消静音

## 运行方式

无需安装任何依赖。直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：直接双击打开
index.html

# 方式二：本地起一个静态服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术实现

| 项目    | 说明                                                                                      |
| ----- | --------------------------------------------------------------------------------------- |
| 渲染引擎  | HTML5 Canvas 2D（`imageSmoothingEnabled = false` 保证像素锐利）                                 |
| 逻辑分辨率 | 320 × 192 像素，通过 CSS 放大                                                                  |
| 精灵规格  | 16 × 22 像素                                                                              |
| 精灵绘制  | 字符映射调色板（`o`=轮廓 / `b`=机身 / `v`=面罩 / `c`=核心 / `g`=金属 / `s`=银 / `w`=武器 / `a`=天线灯 / `e`=高光） |
| 调色板   | 蓝、红两套独立配色，共用同一张精灵表                                                                      |
| 物理    | 重力 `0.45`，跳跃初速 `-7.2`，移动速度 `1.6`                                                        |
| 动画驱动  | `requestAnimationFrame` 主循环 + 帧计时器                                                      |
| 音频系统  | Web Audio API 程序化合成，SFX/BGM 分总线，BGM 16 步前瞻调度器                              |
